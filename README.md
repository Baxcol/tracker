# Привычки и учёба — трекер

Один трекер для учёбы и привычек. Подходы повторяются сколько угодно раз, а проценты, часы и отчёты считаются сами.

## Как это работает

- У каждой активности есть **длина подхода** (английский — 40 мин, зубы — 3 мин) и **норма** (1 в день, 3 в неделю и т.д.).
- Кнопка **«+ 40 мин»** добавляет подход: +100% и +40 минут. Повторять можно без ограничений. Всё сверх нормы идёт в статистику как бонус.
- **Серия** идёт, если за день выполнены все обязательные дневные нормы.
- У активности можно задать **темы** (например, у английского: комиксы, сериал, грамматика). Новая тема добавляется кнопкой «+ Тема», а при добавлении подхода тему можно создать прямо на месте.
- **Календарь:** сверху полоска недели, а по нажатию на дату открывается полный календарь. Зелёный кружок — минимум дня выполнен, красный контур — не выполнен.
- **Статистика текстом:** день, неделя, месяц, всё время. Время, «суммарно %», «норма %», баланс между активностями, разбивка по дням и неделям.
- **Заполнить задним числом:** если привычка у тебя уже есть, укажи дату начала и приложение отметит прошедшие дни за один раз (с предпросмотром и кнопкой «Отменить»).
- **Темы оформления:** светлая, тёмная, киберпанк, средневековье, космос, природа.
- **Таймер** отсчитывает подход. Если остановить раньше, можно засчитать как подход или записать только минуты.

## Запуск на компьютере

Открой `index.html` двойным кликом. Установка не нужна.

## Как выложить или обновить на GitHub (через браузер, без командной строки)

1. Открой свой репозиторий на github.com.
2. Нажми **Add file → Upload files**.
3. Перетащи в окно файлы из распакованного архива: `index.html`, `style.css`, `app.js`, `logic.js`, `sw.js`, `manifest.webmanifest` (папка `icons` не менялась, её можно не трогать). Файлы с теми же именами заменят старые.
4. Внизу нажми **Commit changes**. Через 1–2 минуты обновление появится на сайте.
5. На телефоне открой приложение, закрой его и открой ещё раз. Новая версия подхватится при втором открытии. Данные при этом **сохраняются**.

## Важно знать

- Данные лежат **только в памяти телефона** (внутри браузера). Если очистить данные сайта или удалить приложение, история пропадёт. Раз в неделю-две делай **копию** в Настройках: файл можно загрузить обратно.
- Данные на компьютере и на телефоне **не синхронизируются**. Переносить можно через копию.

## Структура

| Файл | Что делает |
| --- | --- |
| `logic.js` | Вся математика: проценты, серии, отчёты, календарные статусы. Без интерфейса. |
| `app.js` | Экраны и кнопки, сохранение, таймер, копии. |
| `style.css` | Внешний вид и все темы. |
| `sw.js`, `manifest.webmanifest` | Установка как приложение и офлайн-режим. |
